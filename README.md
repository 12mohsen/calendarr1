# تقويم — تطبيق قابل للتثبيت (PWA)

هذا المجلد صار تطبيق ويب قابل للتثبيت على ويندوز وأندرويد و iOS.

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | التطبيق نفسه (أُضيف له زر «تثبيت التطبيق» وتسجيل الـ service worker) |
| `manifest.webmanifest` | بيان التطبيق: الاسم، الأيقونات، الألوان، وضع `standalone` |
| `sw.js` | service worker: يخزّن ملفات التطبيق ليعمل بدون إنترنت |
| `icons/` | أيقونات التطبيق (192، 512، maskable، Apple، ونسخة SVG) |
| `start-server.bat` | تشغيل خادم محلي بنقرة واحدة للتجربة والتثبيت |
| `index.html.bak` | نسخة احتياطية من الملف الأصلي قبل التعديل |

## مهم: التثبيت لا يعمل بفتح الملف مباشرة

فتح `index.html` بنقرة مزدوجة يستخدم عنوان `file://` والمتصفحات لا تسمح بتثبيت التطبيقات
أو تشغيل service worker من هذا العنوان. لازم يُفتح عبر `http://localhost` أو موقع `https`.

## الطريقة ١: تجربة محلية (الأسرع)

1. شغّل `start-server.bat` بنقرة مزدوجة.
2. سيفتح المتصفح على `http://localhost:8080/index.html`.
3. اضغط زر **«تثبيت التطبيق»** داخل الصفحة، أو أيقونة التثبيت في شريط عنوان المتصفح.

يتطلب وجود Python أو Node.js على الجهاز.

## الطريقة ٢: نشر دائم على الإنترنت (موصى بها)

حتى يعمل التطبيق على الجوال ويبقى متاحاً دائماً، ارفع محتويات هذا المجلد على استضافة HTTPS:

- **GitHub Pages**: أنشئ مستودعاً، ارفع الملفات، ثم فعّل Pages من إعدادات المستودع.
- **Netlify Drop**: اسحب المجلد إلى `app.netlify.com/drop` وستحصل على رابط فوراً.
- **Cloudflare Pages** أو أي استضافة تدعم HTTPS.

بعد النشر: افتح الرابط في Chrome أو Edge → زر «تثبيت التطبيق».
وعلى الآيفون: افتح الرابط في Safari → زر المشاركة → «إضافة إلى الشاشة الرئيسية».

## عند تعديل التطبيق لاحقاً

بعد أي تعديل على `index.html`، غيّر رقم الإصدار في أول سطر من `sw.js`:

```js
const CACHE = "taqweem-v2";
```

هذا يجبر المتصفح على تحديث النسخة المخزّنة عند المستخدمين.
